# Technology Stack

## Core Language & Environment
- **Language:** Python (>=3.12)
- **Package Manager:** `uv`

## Data Acquisition & Analysis
- **Financial Data Source:** `yfinance` (Yahoo Finance API wrapper)
- **Data Manipulation:** `pandas`
- **Data Visualization:** `matplotlib`
- **Experimentation/Prototyping:** `jupyter`, `ipykernel`

## Database & Storage
- **Current Database:** SQLite (Local caching)
- **ORM (Planned):** SQLAlchemy

## Development Tools
- **Linting & Formatting:** `ruff`
- **Git Hooks:** `pre-commit`

## Architecture
- **Agent Framework:** Custom implementation (located in `finance_agent/agent/`)
